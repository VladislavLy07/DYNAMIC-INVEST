# Дорожная карта

## 1.0 — проверяемый MVP

Обзор капитала, редактируемый портфель с LocalStorage, калькулятор, календарь и три экономических сценария. Демонстрационные источники, две темы, адаптивная навигация, модульные тесты и GitHub Pages.

## 1.1 — инструменты и рыночные источники

Разделить номинал, цену и количество. Добавить расписания купонов и амортизации, НКД, доходность к погашению, дюрацию и XIRR. Подключить проверенные источники с датами обновления и статусом доступности.

## 1.2 — риск, налоги и отчётность

Развить анализ концентрации, валютного и процентного риска, сроков и ликвидности. Создать каталог версионируемых налоговых правил с годом, источником и проверкой условий льгот. Добавить Capital Review и экспорт PDF.

## 2.0 — сервер и финансовый аналитик

Добавить API на FastAPI и хранилище PostgreSQL или Supabase. Интегрировать серверный аналитический модуль OpenAI с валидацией источников и результатов.
