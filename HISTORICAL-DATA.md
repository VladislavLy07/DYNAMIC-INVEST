# Исторические данные

Рыночные ряды Банка России покрывают 2023, 2024, 2025 и 2026 годы до последней публикации. На графике выбранного года отображаются строки до указанной даты. Для инфляции дата строки обозначает конец измеряемого месяца. Точная дата публикации отдельно не хранится, поэтому исторический график инфляции нельзя использовать как торговый сигнал.

Архив продуктов содержит шесть отдельно проверенных наблюдений. Пять основаны на датированных публикациях ПСБ, одно — на официальной карточке Токеона. По году можно просмотреть все наблюдения, включая материалы позднее выбранного дня. Режим «На дату» требует совпадения даты наблюдения либо подтверждённого интервала действия. Ни одна карточка частичного покрытия автоматически не переносится на текущую дату.

Запустите `node scripts/archive/probe.mjs` для повторной проверки двух URL ПСБ. Wayback предоставил метаданные снимка 19.05.2022 как ближайшего предшествующего наблюдения для запроса за 2023 год и двух снимков 2026 года. Снимки к выбранным датам 2024 и 2025 не найдены в результате проверки запроса. Запрос выбранной коллекции Common Crawl вернул 404. Это результат конкретных запросов, доступность остальных коллекций не проверялась.

Адаптер Common Crawl поддерживает чтение ограниченной записи WARC с обязательным ответом HTTP 206 и лимитом декомпрессии. Извлечение подтверждённых банковских тарифов из WARC и снимков остаётся отдельной работой.
