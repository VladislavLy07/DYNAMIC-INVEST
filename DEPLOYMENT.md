# GitHub Pages

Исходная проверка подтвердила Pages source GitHub Actions, успешное развёртывание main в запуске [45993444403](https://github.com/VladislavLy07/DYNAMIC-INVEST/actions/runs/45993444403) и HTTP 200 на [публичном URL](https://vladislavly07.github.io/DYNAMIC-INVEST/). На момент подготовки ветки по этому адресу работает версия 1.0.

После одобрения и слияния ветки в main workflow проверит код, подготовит `dist/`, подтянет снимок и опубликует артефакт. Vite base — `/DYNAMIC-INVEST/`. Hash-маршрутизация позволяет открывать подстраницы без обратного серверного маршрута.

При ошибке deploy-pages 404 проверьте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Если раздел ещё не включён, администратор должен выбрать этот источник и сохранить настройку. В **Settings → Environments → github-pages** проверьте разрешение ветки main. Затем откройте **Actions → Проверка и публикация → Run workflow**, выберите main и убедитесь, что сборка, настройка и публикация успешно завершились.

Автоматическая попытка обновления назначена на 04:37 UTC ежедневно. Расписание можно изменить в `.github/workflows/pages.yml`. Время фактического старта зависит от GitHub. Обновление сохраняется в артефакте Pages. Коммиты данных и запуск каскадного workflow не требуются. При полном сбое можно опубликовать проверенный снимок из репозитория вручную тем же workflow.
