# Работа с DYNAMIC INVEST

- Создавайте изменения в этом репозитории. DYNAMIC INVEST имеет собственный жизненный цикл и не зависит от BANKFLOW.
- Финансовые функции должны быть детерминированными. Передавайте дату и снимок курсов явно. Храните ставки и денежные суммы в исходных единицах и округляйте отображение отдельно.
- При изменении финансовой логики добавляйте модульные тесты для соответствующей формулы, граничных дат и сценариев.
- Указывайте допущения и происхождение данных в интерфейсе. Храните токены провайдеров на сервере при появлении интеграций.
- Сохраняйте совместимость с сохранёнными данными или добавляйте версионированную миграцию.
- Перед PR выполните `npm ci`, `npm test` и `npm run build`.
- Сверяйтесь с PLANS.md. По завершении этапа обновляйте IMPLEMENTATION-STATUS.md, ACCEPTANCE-CHECKLIST.md, CHANGELOG.md и NEXT-STEPS.md.
- Проверяйте сторонние данные до преобразований. Сохраняйте время наблюдения, подтверждённый период действия, источник и последний корректный снимок отдельно.
- В событиях отделяйте движение номинала, денежный доход, изменение оценки и налоговые обязательства. Проверяйте согласованность графиков, таблиц и экспортов.
- Используйте ветку задачи. Слияние в main и принудительная публикация истории не входят в полномочия рабочего PR.
