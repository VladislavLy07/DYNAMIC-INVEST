# Архитектура

React, TypeScript и Vite формируют статическое приложение. `src/main.tsx` связывает активный портфель, режим времени, выбранный горизонт, сценарий и валюту отображения. Графики используют Recharts, токены и адаптивная раскладка находятся в `src/style.css`.

| Модуль | Назначение |
| --- | --- |
| `src/finance` | Проверка типов, сохранённый базовый калькулятор 1.0, журнал, дисконтирование, цели, облигационные метрики |
| `src/portfolio` | Схема 2, миграция 1.0, бюджет, импорт и LocalStorage |
| `src/tax` | Правила банковских процентов по годам |
| `src/market` | Прочитанные снимки, выборка по датам, версии продуктов, покрытие архивов |
| `src/analytics`, `src/features` | Метрики капитала, сценарии, концентрация и экономика воронки |
| `src/reporting` | CSV, ICS и локальная загрузка файлов |
| `scripts/adapters`, `scripts/archive` | Получение и нормализация официальных наблюдений и архивных индексов |
| `src/ui` | Экраны, общие компоненты расчётов и аналитическая детализация |

Капитал, диаграмма, сценарии, календарь и финансовый отчёт получают значения из `projectLedger`. Обработка исторических наблюдений отделена от договора. Модель текущего снимка и прогнозируемые события не заменяют бухгалтерский учёт фактических операций.

Рыночный JSON загружается с того же origin под base URL. Архивные метаданные и профессиональные экраны загружаются по требованию. Планировщик GitHub Actions записывает снимок в артефакт Pages. Постоянный сервер отсутствует.

В продолжении добавлены `src/backtest` для исторического воспроизведения, `src/tax/securities.ts` для инвестиционных баз и `src/features/china.ts` для валютного сравнения. Прогнозный журнал принимает годовые параметры через `ProjectionOptions.years`. Модули PDF и XLSX загружаются по запросу. PDF содержит встроенный кириллический шрифт DejaVu, лицензия размещена рядом со шрифтом. XLSX создаётся как архив Open XML, данные записываются числами либо строками без исполняемых формул.

## Каталог 6.4

`src/market/fundDisclosures.ts` хранит проверяемый снимок раскрытий управляющей компании с устойчивыми номерами правил. `src/finance/miniSlides.ts` использует существующие налоговые модули для применения ставок, независимо от интерфейса. Общие параметры сценария находятся в состоянии приложения. Каждая строка каталога отдельно хранит признак раскрытия. Настройки каталога действуют в текущем сеансе.
