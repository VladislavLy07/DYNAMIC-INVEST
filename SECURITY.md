# Безопасность

- Портфели и параметры сохраняются только в браузере под ключами `dynamic-invest:`. Другие приложения на том же origin технически могут иметь доступ к LocalStorage. Используйте обезличенные данные.
- Импорт JSON и CSV ограничен 1 МБ, валидируется перед записью. Проверяются даты, диапазоны, графики, объём портфеля и бюджет. JSON заменяет данные после явного действия, CSV добавляет только базовые позиции в активный портфель.
- React выводит внешние сообщения как текст. URL источников снимка и архива проверяются по списку хостов. В HTML интерфейса внешние документы не вставляются.
- CSV экранирует текстовые формулы и кавычки, ICS экранирует управляющие разделители. Экспорт неизвестных входных данных в XLSX ещё не поддерживается.
- Workflow проверки имеет `contents: read`, токен записи Pages и право OIDC доступны только работе публикации. В checkout выключено сохранение учётных данных.
- Модули загрузки задают предел размера ответа, таймаут и запрет перенаправлений. Отчёт `npm audit` проверяется перед PR.
- Приложение не запрашивает секреты, персональные клиентские данные, учётные данные банка и средства на операции.
