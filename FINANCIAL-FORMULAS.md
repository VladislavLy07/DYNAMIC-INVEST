# Финансовые формулы

## Начисление и оценка

- В дневной модели каждый день после входной даты до даты выплаты включительно добавляется остаток × ставка × доля года. Знаменатель равен 365 или 366 по календарному году дня. В модели минимального остатка используется минимум за расчётный отрезок с раздельными дневными ставками.
- Ввод остатка считается снимком на расчётную дату. При старте внутри договорного периода модель рассчитывает будущую часть периода. Изменения ставки и переводы вступают в расчёт на введённую дату.
- Капитализация добавляет выплату к базе начислений отдельной записью. При досрочном выходе в дневной модели доход пересчитывается по условной ставке ACT/365 на исходную сумму. Пролонгация использует введённую ставку и первоначальную длительность в днях.
- Фонд, акция и золото по умолчанию дают переоценку по годовой модели. Сценарная цена в момент t равна исходной оценке × (1 + ставка)^(дней/365).
- Для долга берутся отдельные суммы дохода и возврата номинала из графика. Без графика используется регулярная модель 1.0. При частичном погашении разница между номиналом и оценкой пропорционально проходит через переоценку.
- Статическая комиссия применяется ежемесячно к исходной оценке до даты погашения. Вводите только комиссии, которые ещё не включены в оценку.
- Реальная покупательная способность получается делением конечного сценарного капитала на индекс (1 + инфляция)^(месяцев/12). Для капитала с внешними движениями простой показатель реальной доходности скрыт.

## Доход и журнал

Валовая прибыль = начисления + переоценка.

Чистая прибыль = валовая прибыль − комиссии − условное налоговое обязательство.

Капитал на конец периода = начальная оценка + чистая прибыль + внешние пополнения − внешние изъятия.

Возврат номинала, реинвестирование и внутренние переводы перемещают средства внутри капитала. Выплаты не увеличивают прибыль второй раз после начисления. Денежные суммы округляются Decimal ROUND_HALF_UP до копеек на уровне события. Вывод вычисленных коэффициентов использует числа двойной точности.

## Нормы доходности

XIRR ищет корень суммы дисконтированных потоков ACT/365. Ряд с несколькими сменами знака считается неоднозначным. CAGR рассчитывается по пропорции итогового и исходного капитала при отсутствии внешних потоков. TWR перемножает доходы последовательных подынтервалов при наличии независимых оценок до внешнего потока.

Отдельная полная цена используется для YTM и дюрации в точном графике облигаций. НКД оценивается по доле истёкших дней между соседними равными купонами. Оферты, банковские конвенции конкретных выпусков и отдельные ставки реинвестирования купонов требуют дополнительных правил.

## Переопределения по годам

Для выбранного сценария можно задать строку 1 января конкретного календарного года. Она переопределяет инфляцию, курсы USD/CNY, сдвиг ставок накопительных счетов, темп цены, доходность облигаций, кредитный спред и условный налог. У незаданных лет остаются базовые параметры. Фиксированные договорные ставки по вкладам сохраняются. В дневной модели процент меняется по дням, в модели регулярных платежей ставка подбирается по дате платежа.

Темп цены на годовой границе меняет скорость накопления, а переоценка облигаций использует остаточную дюрацию в точках траектории. Прогнозная инфляция на отдельных годах компонуется по ACT/ACT. Курсовые шоки каждого года задают уровень к исходному курсу. Движения конвертируются по параметрам года выплаты. Валютная переоценка применяется к оставшейся стоимости позиции и не затрагивает уже возвращённый номинал.

## RUB / CNY

Сравнение депозитов использует ACT/365, простой процент, пользовательскую ставку налога на проценты и двусторонний валютный спред. Входной курс умножается на (1 + спред), выходной на (1 − спред). Безубыточный курс равен итоговой RUB-сумме, разделённой на итоговую CNY-сумму после поправки на спред выхода. Налог на результат обмена валюты требует отдельного расчёта.


## Сценарии в мини-слайдах

Для паёв со стартовой суммой `P`, годовым допущением `r` и сроком `t` в месяцах модель использует `V = P × (1 + r)^(t/12)`. Прибыль до НДФЛ равна `V − P`, результат после налога равен `V − T`. Среднегодовая доходность из итоговой суммы `W` равна `(W/P)^(12/t) − 1`. Расходы фонда подразумеваются внутри допущения по цене пая. Надбавки, скидки, тариф брокера и распределения по паям не входят в расчёт.

Для вклада и условного ЦФА применяется ACT/365 и выплата по окончании срока. На модельном счёте начисления по фактическим дням капитализируются ежемесячно. Для облигации задаются цена и погашение по номиналу, полугодовой купон без реинвестирования и расчёт НДФЛ отдельно по годам выплаты. Для золота применяется рост цены и один дисконт 2% при продаже.
