# Точка продолжения

Работа продолжается в `feat/dynamic-invest-5.0-ultra` и PR №2. Итерация добавила каталог официальных снимков ПСБ, архив, расчёт НДФЛ по бумагам и дивидендам, исторический журнал, параметры по годам, валютную лабораторию и отчёты. Статусы приведены в IMPLEMENTATION-STATUS.md и ACCEPTANCE-CHECKLIST.md.

1. Уточнить разрешённый прямой источник тарифов ПСБ. Проверить документ, интервал действия и матрицу для каждого продукта. Добавлять новые версии без перезаписи старых. Проверить доступ к расширенным рядам фондов и облигаций, публикации УК ПСБ и Токеона.
2. Привести исторические даты к подтверждённым временам публикаций. Подключить корпоративные действия, цены биржевых инструментов и исторические банковские договоры с валидированными событиями. Поддержать импорт фактических операций из нескольких форматов.
3. Расширить налоги. Проработать переносы нескольких вкладов, необращающиеся бумаги, ЦФА, ИИС, вычеты, иностранные дивиденды и комиссии с документальными правилами. Учитывать единый резерв до выплаты.
4. Расширить ликвидность, АСВ, стрессы, Smart Alerts и учебные кейсы. Сопоставить расчёты с независимыми эталонами.
5. После решения владельца о слиянии проверить workflow из main, публичный URL, ассеты, экспорт и JSON. Действия при 404 описаны в DEPLOYMENT.md.

Перед дальнейшим PR выполните `npm ci`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` и `npm run test:browser`.
