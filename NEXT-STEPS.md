# Точка продолжения

Основная разработка идёт из ветки `feat/dynamic-invest-5.0-ultra`. Версия 1.0 находится в main. Базовый источник, журнал и каркас интерфейса уже работают.

1. Начать с 5.0.5 и 5.0.6. Проверить разрешённый прямой доступ к текущим документам ПСБ, УК ПСБ и Токеона. Для каждого действующего тарифа сохранить матрицу и подтверждённый интервал действия. Подключить адаптеры к тому же снимку, не заменяя частичные версии.
2. Улучшить полноту архива. Использовать конкретные документы и сверить даты доступности. Подключить результаты диапазонов Common Crawl только после подтверждения исходного URL и содержания. Доработать отсутствие точной даты публикации инфляции.
3. Продолжить 5.0.3 и 5.0.4. Хранить фактические операции, сверять остатки, добавить долгосрочные депозиты, отдельные инвестиционные базы и тестовые эталоны ФНС. Учитывать единый налоговый резерв до момента выплаты.
4. Построить историческую портфельную симуляцию с явным отказом при нехватке данных. Добавить сценарии по годам, динамические тарифы и риск ликвидности.
5. Продолжить профессиональные инструменты после закрытия этих критериев. Предусмотреть автоматический PDF с кириллицей, XLSX, Russia–China Lab, события Smart Alerts и согласованный сервер аналитика.
6. После решения владельца о слиянии проверить новый запуск GitHub Actions из main, публичный URL, ассеты и JSON. Действия при 404 описаны в DEPLOYMENT.md.

Перед продолжением выполните `npm ci`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` и `npm run test:browser`. Правки формул сопровождать независимыми примерами и проверкой журнала.
